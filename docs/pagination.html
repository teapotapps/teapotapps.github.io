Query Pagination Engine

Built-in pagination engine supporting both ORM model queries and manual Raw SQL queries with automated parameter escaping and metadata calculation.

1. Overview

Pagination in TeapotApps lives in src/libs/pagination.js. It automatically reads req.query.page and req.query.limit, calculates offsets, executes count queries, and formats metadata ready for responseApi.

2. Model-Based Pagination

Use paginate(model, req.query, options) for standard Sequelize model queries:

import { paginate } from '../libs/pagination.js';
import { responseApi } from '../libs/RestApiHandler.js';
import ProductModels from '../models/ProductModels.js';

export const getAll = async (req, res) => {
    const result = await paginate(ProductModels, req.query, {
        where: { status: 1 },
        order: [['id', 'DESC']]
    });

    return responseApi(res, result.data, result.meta, "Products retrieved");
};

3. Manual Raw SQL Pagination

For complex queries involving table JOINs or aggregations, use paginateQuery:

import { paginateQuery } from '../libs/pagination.js';
import { responseApi } from '../libs/RestApiHandler.js';

export const getSalesReport = async (req, res) => {
    const rawSql = `
        SELECT o.id, o.invoice_no, u.name as customer_name, o.total_amount
        FROM orders o
        JOIN users u ON o.user_id = u.id
        WHERE o.status = :status AND o.created_at >= :startEpoch
        ORDER BY o.id DESC
    `;

    const result = await paginateQuery(rawSql, req.query, {
        replacements: {
            status: 'PAID',
            startEpoch: 1700000000
        }
    });

    return responseApi(res, result.data, result.meta, "Orders retrieved");
};

4. Parameter Escaping & Flexibility

Automatic Escaping: All parameters passed through replacements: { ... } are strictly sanitized and bound by the database driver, preventing SQL injection vulnerabilities.

Dynamic Raw Fragments: If your query requires dynamic column ordering or unescaped clauses, interpolate strings into your base query before passing it to paginateQuery: 

const allowedSortColumns = ['id', 'price', 'created_at'];
const sortBy = allowedSortColumns.includes(req.query.sort) ? req.query.sort : 'id';

const sql = `SELECT * FROM products WHERE status = :status ORDER BY ${sortBy} DESC`;
const result = await paginateQuery(sql, req.query, { replacements: { status: 1 } });

5. Standard Output Envelope

The client receives a complete pagination summary inside the meta field:

{
  "data": [ ... ],
  "meta": {
    "page": 2,
    "limit": 10,
    "total_data": 48,
    "total_pages": 5,
    "has_next": true,
    "has_prev": true
  },
  "status": {
    "code": 0,
    "message_client": "Products retrieved"
  }
}
Safety Cap: limit is automatically capped between 1 and 100 to protect your database against runaway memory allocation.
