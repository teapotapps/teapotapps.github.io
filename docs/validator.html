Request Validator

Zero-dependency, functional validation middleware. No Joi or Zod bloat required — validate request payloads using plain JavaScript logic.

1. Why Functional Validation?

In standard Node.js applications, validating request parameters often requires heavy npm packages or messy if/else chains in controllers. TeapotApps provides a built-in functional validator in src/core/validator.js.

A rule is simply a function: return true to pass, or return a string error message to reject.

2. Basic Route Validation

import { Router } from 'express';
import { validate } from '../core/validator.js';
import * as ProductController from '../controllers/ProductController.js';

const router = Router();

router.post('/products', validate({
    name: (val) => Boolean(val && val.trim()) || "Nama produk wajib diisi",
    price: (val) => (Number(val) > 0) || "Harga harus lebih besar dari 0",
    sku: (val) => (val && val.length >= 3) || "SKU minimal 3 karakter"
}), ProductController.create);

3. Standard 422 Response

If any rule fails, execution immediately halts and returns a standardized TeapotApps error envelope:

{
  "data": null,
  "meta": null,
  "status": {
    "code": 422,
    "message_client": "Harga harus lebih besar dari 0"
  }
}

4. Built-in Rule Helpers

TeapotApps also exports optional rule predicates for common validations:

import { validate, rules } from '../core/validator.js';

router.post('/register', validate({
    email: rules.email("Format email tidak valid"),
    name: rules.required("Nama wajib diisi"),
    age: rules.number("Usia harus berupa angka"),
    password: rules.min(8, "Password minimal 8 karakter")
}), AuthController.register);

5. Validating Query or Params

By default, validate(schema) checks req.body. To validate req.query or req.params, pass the target as the second argument:

// Validating query parameters:
router.get('/reports', validate({
    year: (val) => Number(val) >= 2020 || "Tahun minimal 2020"
}, 'query'), ReportController.getAnnualReport);
Zero Dependency: This validator adds 0 KB to your npm footprint and executes with native JavaScript speed.
