Time & Timezone Utilities

Zero-dependency date, epoch, and timezone formatting utilities for TeapotApps. Clean in-file configuration with no heavy Moment or Dayjs libraries.

1. In-File Timezone Configuration

To keep your .env file minimal and unbloated, the default timezone is declared right at the top of src/libs/TimeHandler.js: 

// src/libs/TimeHandler.js
export const DEFAULT_TIMEZONE = 'Asia/Jakarta';

You can change this constant to any standard IANA timezone (e.g. 'UTC', 'Asia/Tokyo', 'America/New_York').

2. Getting Epoch Timestamps

Perfect for database timestamps, token expiration checks, or cache expiry keys:

import { TimeHandler } from '../libs/TimeHandler.js';

// Unix timestamp in seconds (standard epoch):
const epochSeconds = TimeHandler.now(); // e.g. 1789035456

// Unix timestamp in milliseconds:
const epochMs = TimeHandler.nowMs(); // e.g. 1789035456123

// Convert existing Date or ISO string to epoch seconds:
const userCreatedAt = TimeHandler.toEpoch(user.created_at);

3. Formatting Date Strings

Formats any date into a clean YYYY-MM-DD HH:mm:ss string:

// Uses default in-file timezone (Asia/Jakarta):
const formatted = TimeHandler.format(new Date()); 
// Output: '2026-09-10 17:15:30'

// Override timezone on-the-fly:
const utcString = TimeHandler.format(new Date(), 'UTC');
const tokyoString = TimeHandler.format(new Date(), 'Asia/Tokyo');

4. Daily Boundaries (Start & End of Day)

Crucial for transactional filtering, daily ledger summaries, or sales reports:

// Date only string (YYYY-MM-DD):
const today = TimeHandler.toDateString(); // '2026-09-10'

// Start of Day (00:00:00):
const start = TimeHandler.startOfDay(); // '2026-09-10 00:00:00'

// End of Day (23:59:59):
const end = TimeHandler.endOfDay(); // '2026-09-10 23:59:59'
Zero-Dependency: Built using native Intl.DateTimeFormat engines built into V8, delivering optimal execution speed without memory bloat.
