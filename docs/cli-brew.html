CLI Generator (teapotapps brew)

Fast, modular scaffolding commands to generate controllers, Sequelize models, Express middlewares, and complete API modules with zero boilerplate.

1. Overview

Rather than manually creating files or relying on heavy class-based OOP generators, TeapotApps introduces the brew command. It writes idiomatic, pure ECMAScript Module (ESM) functions directly into your project structure.

2. Brew Controller

Generates an ESM controller in src/controllers/<Name>Controller.js with descriptive CRUD handlers using standard responseApi:

# Syntax:
teapotapps brew controller <name>

# Example:
teapotapps brew controller products

# Terminal Output:
# 🍵 Brewed controller: src/controllers/ProductsController.js

Generated Controller Output (src/controllers/ProductsController.js):

import { responseApi } from "../libs/RestApiHandler.js";

export const getAll = async (req, res) => {
    return responseApi(res, [], null, "Products list retrieved successfully");
};

export const getById = async (req, res) => {
    const { id } = req.params;
    return responseApi(res, { id }, null, "Products detail retrieved successfully");
};

export const create = async (req, res) => {
    return responseApi(res, req.body, null, "Products created successfully");
};

export const update = async (req, res) => {
    const { id } = req.params;
    return responseApi(res, { id, ...req.body }, null, "Products updated successfully");
};

export const remove = async (req, res) => {
    const { id } = req.params;
    return responseApi(res, { id }, null, "Products deleted successfully");
};

3. Brew Model

Generates a Sequelize model in src/models/<Name>Models.js integrated with DataTypesCustom and Unix timestamp columns:

# Syntax:
teapotapps brew model <name>

# Example:
teapotapps brew model products

# Terminal Output:
# 🍵 Brewed model: src/models/ProductsModels.js

Generated Sequelize Model Output (src/models/ProductsModels.js):

import db from "../configs/database.js";
import DataTypesCustom from "../libs/DataTypesCustom.js";
const { TYPES } = DataTypesCustom;

const ProductsModels = db.define("products", {
    id: {
        type: TYPES.BIGINT,
        primaryKey: true,
        autoIncrement: true,
    },
    name: {
        type: TYPES.STRING(255),
        allowNull: false,
    },
    created_at: {
        type: TYPES.BIGINT,
        allowNull: true,
    },
    updated_at: {
        type: TYPES.BIGINT,
        allowNull: true,
    },
}, {
    freezeTableName: true,
    timestamps: false,
});

export default ProductsModels;

6. Brew Full API Module (Active Model CRUD)

Creates Controller + Model + wires routes in src/routes/api.js in one shot with real Sequelize model queries:

# Public routes:
teapotapps brew api products

# Protected routes (automatically attaches verifyToken middleware):
teapotapps brew api products --auth

# Terminal Output:
# 🍵 Brewed model: src/models/ProductsModels.js
# 🍵 Brewed active controller: src/controllers/ProductsController.js
# 🍵 Wrote API routes to: src/routes/api.js

Generated Active Controller Output (src/controllers/ProductsController.js via brew api):

import { responseApi } from "../libs/RestApiHandler.js";
import ProductsModels from "../models/ProductsModels.js";

export const getAll = async (req, res) => {
    try {
        const data = await ProductsModels.findAll();
        return responseApi(res, data, null, "Products list retrieved successfully");
    } catch (error) {
        return responseApi(res, null, error.message, "Failed to retrieve products list", 500);
    }
};

export const getById = async (req, res) => {
    try {
        const { id } = req.params;
        const data = await ProductsModels.findByPk(id);
        if (!data) {
            return responseApi(res, null, "Data not found", "Products not found", 404);
        }
        return responseApi(res, data, null, "Products detail retrieved successfully");
    } catch (error) {
        return responseApi(res, null, error.message, "Failed to retrieve products", 500);
    }
};

export const create = async (req, res) => {
    try {
        const data = await ProductsModels.create(req.body);
        return responseApi(res, data, null, "Products created successfully", 201);
    } catch (error) {
        return responseApi(res, null, error.message, "Failed to create products", 500);
    }
};

export const update = async (req, res) => {
    try {
        const { id } = req.params;
        const [updated] = await ProductsModels.update(req.body, { where: { id } });
        if (!updated) {
            return responseApi(res, null, "Data not found or no changes", "Products not updated", 404);
        }
        return responseApi(res, { id, ...req.body }, null, "Products updated successfully");
    } catch (error) {
        return responseApi(res, null, error.message, "Failed to update products", 500);
    }
};

export const remove = async (req, res) => {
    try {
        const { id } = req.params;
        const deleted = await ProductsModels.destroy({ where: { id } });
        if (!deleted) {
            return responseApi(res, null, "Data not found", "Products not found", 404);
        }
        return responseApi(res, { id }, null, "Products deleted successfully");
    } catch (error) {
        return responseApi(res, null, error.message, "Failed to delete products", 500);
    }
};
Tip: All generated files follow clean JavaScript ESM conventions without bloated abstract classes. You can immediately customize fields and logic.
