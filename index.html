Folder Convention

Clean Modular Monorepo & Scaffolding

TeapotApps provides a battle-tested structure out-of-the-box. Every folder has a clear, predictable purpose.

my-app/ (Scaffolded Output) Native ESM
├── src/
│ ├── controllers/ # API endpoint logic
│ │ └── WelcomeController.js
│ ├── core/ # Framework routing primitives
│ │ └── routeGroup.js
│ ├── libs/ # RestApiHandler response envelope
│ │ └── RestApiHandler.js
│ ├── middlewares/ # Auth & 418 interceptor
│ │ └── verifyToken.js
│ ├── routes/ # Grouped modular routing
│ │ └── api.js
│ └── views/ # Lightweight server HTML views
│ └── Welcome.js
├── .env # Environment configuration
├── index.js # Application entry point
└── package.json # "type": "module"

Declarative Route Grouping

Define nested routes with specific prefix hierarchies and localized middleware pipelines using the concise routeGroup helper.

Consistent JSON Contract

Standardize responses with responseApi(res, data, meta, message, code). Guarantees consistent front-end consumption across all endpoints.

RFC 2324 Teapot Handling

Integrated status interceptor handles HTTP 418 gracefully, providing playful yet robust error containment for specialized handlers.

Fast Setup

                    
Up and Running in 3 Minutes

                    

                        Zero complex configuration files. Follow these three steps to begin developing.
                    

                


                

                    

                        
01

                        
Scaffold Project

                        
Run the automated interactive generator to configure your project name and settings.

                        npx create-teapotapps my-app
                    


                    

                        
02

                        
Start Dev Server

                        
Enter your directory and run the local development server with instant hot reload.

                        cd my-app && npm run dev
                    


                    

                        
03

                        
Steep Your APIs

                        
Your modular backend will be live on port 3010, ready for custom route groups and controllers.

                        http://localhost:3010/api/wellcome
